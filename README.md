# GitHub CLI 

## Purpose of creation
* ** This repository was created to help people with difficulties about installing the official GitHub CLI (Command Line Interface) by 2 clicks. **

* ** After use on public computers, always logout with command --gh auth logout **

## Propósito de criação
* ** Esse repositório foi criado para ajudar as pessoas com dificuldade sobre instalar o GitHub CLI oficial com 2 cliques. **

* ** Depois do uso em computadores públicos, sempre faça logout com o comando --gh auth logout **
